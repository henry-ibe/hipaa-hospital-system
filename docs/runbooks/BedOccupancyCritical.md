# Runbook: BedOccupancyCritical

## Summary
A hospital department has exceeded 95% bed occupancy for more than 5 minutes.

## Impact
- Department cannot admit new patients
- Patient diversion may be required

## Severity
Warning — P2

## Immediate Steps
1. Identify which department is affected from the alert labels
2. Notify hospital operations team immediately
3. Check if discharge process can be expedited
4. Consider diversion protocol if occupancy hits 100%

## Escalation
Notify hospital operations manager immediately. This is a clinical operations issue not an IT issue.
